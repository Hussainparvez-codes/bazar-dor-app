🛒 বাজার দর | BazarDor

BazarDor is a modern Bengali market price tracking web application that helps users easily explore daily market prices of essential products in Bangladesh. Users can browse different product categories, compare current prices with previous prices, and stay updated with market price changes.

🚀 Technologies Used

Next.js – React framework for building the web application.

React.js – For building interactive user interfaces.

Tailwind CSS – For responsive and modern styling.

HeroUI – For reusable UI components.

MongoDB – Database for storing user information.

Better Auth – For user authentication and account management.

JavaScript (JSX) – Main programming language.

REST API – For fetching market and product data.

Vercel – For deployment and hosting.

✨ Key Features

Daily Market Price Tracking – View the latest prices of essential market products in Bangladesh.

Product Categories – Browse products by categories such as Rice, Lentils, Oil, Fish, Meat, Vegetables, and Spices.

Price Comparison – Compare today's prices with yesterday, last week, and last month to understand price changes.

Price Increase & Decrease Updates – Easily identify products whose prices have increased or decreased.

User Authentication & Profile – Sign up, sign in, and manage your user profile securely using Better Auth.

BazarDor aims to make market price information more accessible and transparent for everyone. With a simple and user-friendly interface, users can quickly check product prices and understand daily market trends.
